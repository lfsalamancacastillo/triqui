# Triqui

Juego de triqui (tres en raya) para dos jugadores, desarrollado en Python con interfaz gráfica (tkinter).

## Cómo se juega

- Dos jugadores se turnan: X empieza y luego juega O.
- Haz clic en una casilla vacía para marcarla.
- Gana quien complete una fila, columna o diagonal con su símbolo.
- Si el tablero se llena sin ganador, la partida termina en empate.
- El botón "Reiniciar" empieza una partida nueva.

## Requisitos

- Python 3.8 o superior (tkinter viene incluido con Python).

## Ejecución

```bash
python triqui.py
```
